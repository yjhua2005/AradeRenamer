AradeRenamer 用户手册

Arade文件更名器（Win32 桌面程序，纯 Win32 API 实现，无第三方运行库依赖）。本手册覆盖全部菜单命令、 标签页用法、音频标签读写、编码转换与常见问题。

1. 快速上手

  1. 添加文件：工具栏「添加文件 / 添加目录」，或把文件/文件夹直接拖进列表，或在资源管理器里右键 「AradeRenamer 更名」。
  2. 设置规则：在下方标签页（整体 / 替换 / 序号 / 添加 / 删除 / 扩展更名 / 标签命名 / 标签写入） 里勾选并填写，各页规则叠加生效（顺序：整体 → 替换 → 删除 → 添加 → 序号 → 扩展更名 → 整体扩展名 → CRC32）。
  3. 预览：列表「预览」列实时显示新名字；状态栏显示 文件数 / 待更名数 / 冲突数。冲突行标红。
  4. 应用：点「更名」(Ctrl+E)。目标已存在时自动加 (2) 后缀；「撤销」(Ctrl+Z) 回退上一批。

打勾列（第一列）取消打勾的行不参与预览和更名；右键列表行可批量打勾/取消/删除。

多选文件与单实例

在资源管理器里选中多个文件、右键「AradeRenamer 更名」时，系统会为每个文件各调用一次本程序。 本程序是单实例的：

  • 第一个调用建立窗口并载入它的文件；
  • 其余调用不另开窗口，而是把自己的文件合并进已有窗口的列表（重复文件自动去重），并把窗口带到前台；
  • 直接双击/带参数启动 exe、把文件拖到 exe 图标上，同样遵循这个规则——永远只有一个窗口。

所以选中 N 个文件右键，结果是一个窗口里列出全部 N 个文件，而不是开 N 个窗口。

2. 标签页详解

2.1 整体

选项说明
文件名大小写大写 / 小写 / 每个单词首字母大写
文件名改成整名替换，支持元变量 <DATE> <TIME> <NAME> <EXT> <.EXT> <PARENT> <SELF> <R> <N>
扩展名大小写 / 扩展名改成对扩展名单独处理
文件过滤如 *.mp3，限定只作用于匹配的文件

2.2 替换

普通文本查找替换；勾选「正则表达式」后按正则替换（$1 反向引用），查找框以 : 开头也会自动启用正则。可忽略大小写。

2.3 序号

模板中 # = 序号，<NAME> = 原名，<SELF> = 当前名。 支持起始值 / 步长 / 位数补零 / 字母编号（0→A，勾「字母大写」出 A，否则 a）。 模板不含扩展名时自动保留原扩展名。

2.4 添加 / 2.5 删除 / 2.6 扩展更名

添加：插入到文件名前/后、扩展名前/后或指定位置。删除：按指定文本、前 N 个、后 N 个、从第 N 个起删 M 个， 作用范围可选文件名或扩展名。扩展更名：添加 / 删除 / 更改 / 大小写，另有「扩展命令」可叠加多个命令词。

「扩展命令」预设里的功能词固定是中文（汉字转换为拼音、 字符顺序颠倒……），界面切成英文也是这样——引擎就是按这些中文词匹配的， 照着点预设或直接照抄进去即可，不要自己翻译成英文。

2.7 标签命名

用音乐文件的标签给文件命名。表达式里 %1艺术家 %2标题 %3音轨 %4专辑 %5年代 %6注释，如 %3.%1 - %2。 文件没有标签时保持原名（不会把名字抹空）。标签值里的 \ / : * ? " < > | 会替换成空格， 避免改名失败或跑进子目录。

2.8 标签写入

把标签写进音乐文件：填写 艺术家/标题/专辑/音轨/年代/流派/注释，或用「文件名表达式」从文件名反解 （如 %1 - %2 匹配「歌手 - 歌名」）。「保存」写打勾/选中的行，「全写」写整个列表。 行为受 设置 > 音乐文件标签 控制（见 §5.2）。

4. 特殊的名字来源与编码转换

4.1 文件名 / 标签的内码转换（BIG5↔GB、Shift-JIS↔中文）

这类命令修的是「按错误代码页误读」的名字：繁体系统里按 Big5 存放的文件名，被 GBK 系统按 GBK 解释后 显示为乱码（或反之）。命令把每个字符取回原代码页的字节、再按目标代码页解释，乱码即恢复为正常文字。

  • 文件名 BIG5 -> GB：文件名是 Big5 字节但被按 GBK 误读 → 修正。
  • 文件名 GB -> BIG5：反向修正。
  • 文件名日文Shift-JIS转中文：文件名是 Shift-JIS 字节但被按 GBK 误读 → 恢复为可正常显示的日文文本。
  • 文件名中文转日文Shift-JIS：把中文名编成 Shift-JIS 字节再按 GBK 误读（在日文系统上显示为中文的场景）。
  • 标签菜单下同名命令（标签 BIG5->GB 等）对的是文件里的标签值，读出来 → 转换 → 写回。
只对确定是「误读」的名字使用。正常的中文名字执行这些命令也可能被改变（它眼里每个字符都可能是误读）。

4.2 以网页标题 / 文本第一行更名

  • 以网页文件的标题更名：读取 <title>…</title> 作为新主名。 自动识别页面编码（UTF-8 / GBK / Big5 / Shift-JIS，看 BOM 和 meta charset），并解开 HTML 实体 （&amp; 等）。只作用于 .htm / .html 文件；列表里没有网页文件时命令不生效。
  • 以文本文件的第一行内容更名：取文本文件第一行（自动跳过 BOM、支持 UTF-8/GBK）作新主名。 只作用于 .txt 文件。

两个命令都是开关式：再点一次同一命令即取消，恢复原名。

4.3 调用文本文件命令

选择一个命令文本文件，每行一条更名指令，程序按指令直接给出新名（见「预览」列）。

# 注释行
旧歌.mp3=新歌.mp3
照片.jpg=旅行            # 新名不带扩展名则保留原扩展名
a.txt	b.txt            # 也可以用 Tab 分隔
  • 按原文件名（含扩展名）匹配，大小写不敏感；匹配不到的行保持原名。
  • 新名里的 \ / : * ? " < > | 会被替换成空格。
  • 匹配到的行仍受其它标签页规则叠加影响（如再勾了「添加」页会继续追加）。

7. 资源管理器右键菜单 与 发送到

7.1 右键菜单（注册表方式）

菜单「选项 > 添加右键菜单(管理员)」在三个位置注册「AradeRenamer 更名」： 所有文件、文件夹、目录背景。它写在 HKEY_CLASSES_ROOT 下（*\shell\AradeRenamer、 Folder\shell\AradeRenamer、Directory\Background\shell\AradeRenamer）， 对机器上所有用户生效，因此需要管理员权限——菜单名字里那个「(管理员)」就是这个意思。 「卸载右键菜单(管理员)」移除它们。

多选文件时，系统会为每个文件各调用一次程序；本程序是单实例的，全部文件会合并进同一个窗口（见 §1）。

关于管理员权限：
  • 不用自己先去「以管理员身份运行」：直接点菜单，程序发现自己没提权会弹一个询问框， 点「确定」就以管理员身份重启一份自己来完成这件事，期间系统会弹一次 UAC让你确认。 （重启起来的那份只干这一件事，干完就退出，不会多开一个主窗口。）
  • 已经用管理员身份运行着 exe 时再点，就直接写了，不再弹 UAC。
  • 不想走提权的话，也可以退出程序后右键 AradeRenamer.exe 选 「以管理员身份运行」，再执行同一个命令；或者手工导入随附的 AradeRenamer.reg （注册表编辑器导入同样需要管理员权限）。
  • 程序平时不常驻管理员权限，只有这一下才提权。
  • 万一写入还是被拒绝（公司机器禁改注册表、UAC 被取消），程序会明确提示 「没有权限写入注册表（访问被拒绝）」，而不是只说「成功 0 条」。
  • 卸载时会顺带清掉早期版本写到别处的残留键（含用户级 HKCU\Software\Classes 下的同名键——它在合并视图里优先级更高，会把新写的值盖住）。

7.2 发送到菜单（快捷方式方式，不是注册表）

菜单「选项 > 添加到 发送到 菜单」会在 %APPDATA%\Microsoft\Windows\SendTo\ 放一个指向本程序的快捷方式 （不走注册表——Windows 的发送到菜单就是扫描这个文件夹里的 .lnk）。 「从 发送到 菜单移除」删掉它。

用法：资源管理器选中文件 → 右键 → 发送到 → AradeRenamer 更名。

发送到和右键菜单的一个区别：多选文件时，发送到会把所有文件一次性放在命令行里 传给程序（一次调用带 N 个文件）；右键菜单则是一个文件调用一次。两种方式最终都是单实例、 全部文件进同一个窗口的列表（重复文件自动去重）。

8. 其它功能

  • 操作记录：自动记录每批更名；「保存操作记录」存为 .xto，「打开操作记录」载入并挂上撤销批次。
  • 导出当前列表：文件名列表存文本（可选带扩展名/带路径）。
  • 更改文件日期：批量改创建/访问/修改时间（当前时间或自定义）。
  • 界面语言：菜单「选项 > 语言」切换。程序自带简体中文和 English，另有「自动」跟随 Windows 界面语言。选择存在注册表里，下次启动沿用。切换后界面立即重排——标签页里的控件宽度是 按当前语言的文字实际长度算出来的，不会因为英文比中文长就挤出截断。
  • 赞助 / 联系：工具栏最右侧的 ❤️ 按钮，或菜单「帮助 > 关于 > 赞助/联系」， 打开的是同一个窗口：三个收款码，外加开源地址、QQ 群号和邮箱。 后两条（QQ 群号、邮箱地址）点一下就复制到剪贴板，那一行会闪一下「已复制」； 「开源地址」和「邮箱」两行是链接，点击时同样先把地址复制进剪贴板，再交给系统默认程序打开。 万一打不开（比如机器上没装邮件客户端），地址已经在剪贴板里，直接粘贴即可。
  • 窗口置顶 / 屏幕居中：工具栏图钉按钮切换置顶；窗体每次启动都显示在屏幕中央， 启动之后可随意拖动到任意位置，菜单「选项 > 窗口居中显示」可随时把窗体挪回中央。
  • 拖放：把文件或文件夹拖进列表即添加。

8.1 添加一种新语言

语言包是 exe 旁边的 Language\*.ini，一个语言一个文件（UTF-8，键 = 值，支持 \n \t \\ 转义）。往该目录放一个新 .ini，重新启动后它就会出现在 「选项 > 语言」里，不需要改代码、不需要重新编译。两个内置语言包同时编译进了 exe， 删掉 Language 目录程序照样是完整的中文/英文。

每个语言包开头有三行元信息，缺一不可（lang.name / lang.code 程序要读，lang.author 是给贡献者的署名位）：

; 以 ; 或 # 开头的整行是注释（行尾注释不生效——会被当成值的一部分）
lang.name = 日本語
lang.code = ja-JP
lang.author = 你的署名

lang.author 记的是译者而不是程序作者——别人补一门语言时改这一行就是他的署名。 它会显示在「选项 > 语言」菜单里，格式是 English  (yjhua2005)：语言名后面跟一个括号， 里面是译者。没写 lang.author 的语言包就只显示语言名，不会多出空括号。

做法：复制 Language\lang_en-US.ini（英语是翻译源语言，从英文翻成你的语言最省事）改名成 lang_ja-JP.ini，改上面三行，然后逐条翻译。翻不动的键整行删掉即可，运行期自动退回 简体中文，所以一份只翻了一半的语言包也能用。

英文包是手写的，偶尔会比刚新增的键落后几条。翻译前先跑一次 python tools/extract_lang.py，它会列出这个包漏了哪些键；lang_zh-CN.ini 由脚本生成、键永远最全，拿它当对照表查缺补漏即可。
标签页里的控件宽度会跟着译文长度自动伸缩，所以一般不用担心译文太长把界面挤坏； 只有整排实在放不下时才会压缩——那种情况下精简几条译文即可。

标「—」的是没有设快捷键的命令：ID3 互转、6 条标签编码转换、发送到菜单的 装 / 卸、窗口居中显示和「关于」，都不值得占掉一个常用组合键。 菜单里带括号字母的（如「添加右键菜单(管理员)(A)」）是菜单助记符：先按 Alt+O 展开「选项」菜单，再按那个字母即可，不需要鼠标。 后加的几条统一用 Ctrl+Shift+<字母>：不带 Shift 的 Ctrl+<字母> 基本排满了，而且 Ctrl+A / Ctrl+Z 在输入框里是编辑键，加 Shift 才不会打架。

10. 常见问题

Q：更名后想反悔？
A：点「撤销」(Ctrl+Z) 回退上一批；更早的批次用「打开操作记录」载回。

Q：预览列和结果列什么意思？
A：「预览」是按当前规则算出的新名字；「结果」是上次执行这一行的结局（已更名/已写入标签/跳过/失败）。

Q：标签写进去中文变问号？
A：ID3v1 只有 30 字节定长字段且按系统 ANSI 编码，中文按 GBK 存储；需要完整中文请用 ID3v2 （设置 > ID3标签写入时 选「只写入ID3v2」或「同时写入」）。

Q：以网页标题更名没反应？
A：该命令只对 .htm/.html 生效，且页面里要有 <title>；列表里没有网页文件时命令不会开启。

Q：编码转换命令把我的正常中文名也改了？
A：它按「每个字符都是被误读的字节」处理，只应用于确定是乱码的名字。

Q：在列表里按 Delete 怎么没反应？
A：Delete 只删高亮选中的行。先点一下要删的行（按住 Ctrl / Shift 可多选）再按 Delete； 一行都没选中时它故意什么都不做，免得误按一下整个列表就没了。要清空整个列表， 用右键菜单里的「清空文件列表」。
